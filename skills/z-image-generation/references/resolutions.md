# Z-Image 官方分辨率比例表

官方 Tongyi-MAI Space 预设 33 个组合：3 档基准分辨率 × 6 种比例（横竖各半）。

## 1:1

- 1024x1024 / 1280x1280 / 1536x1536

## 9:7（≈4:3 宽）

- 横: 1152x896 / 1440x1120 / 1728x1344
- 竖: 896x1152 / 1120x1440 / 1344x1728

## 4:3

- 横: 1152x864 / 1472x1104 / 1728x1296
- 竖: 864x1152 / 1104x1472 / 1296x1728

## 3:2（照片感）

- 横: 1248x832 / 1536x1024 / 1872x1248
- 竖: 832x1248 / 1024x1536 / 1248x1872

## 16:9（视频/横幅）

- 横: 1280x720 / 1536x864 / 2048x1152
- 竖: 720x1280 / 864x1536 / 1152x2048

## 21:9（超宽屏）

- 横: 1344x576 / 1680x720 / 2016x864
- 竖: 576x1344 / 720x1680 / 864x2016

## 规则

- 3 档基准：~1024 / ~1280 / ~1536（官方 Resolution Category）
- 用官方预设组合出图最稳；mrfakename Space 虽允许 512–2048 任意整数，但非标尺寸构图可能失衡
- 超宽比（21:9）用 1024 档即可，不必硬上大分辨率
